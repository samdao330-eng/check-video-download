# CHECK VIDEO — tải bộ cài

Tool kiểm tra một tập đã dựng trước khi đăng (MAVA). Tải bản mới nhất ở **[Releases → Latest](../../releases/latest)**.

**Mac** (chip Apple M1 trở lên, macOS 12+): tải file `.dmg` → mở → kéo CHECK VIDEO vào Applications.
Lần đầu mở: chuột phải vào app → Mở → Mở (macOS 15+: mở một lần, rồi Cài đặt hệ thống → Quyền riêng tư & Bảo mật → Vẫn mở).

**Windows** 10/11 64-bit: tải file `Setup-….exe` → chạy → Cài đặt. Nếu báo "Windows protected your PC": More info → Run anyway.
Bản mới: cài đè lên bản cũ, không cần gỡ.
